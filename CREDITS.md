## APS reference data

APS characteristics are based on publicly available information
from Wikipedia and open sources. All effectiveness values in this
mod are **gameplay approximations**, not confirmed real-world
performance. In particular, the Afganit APFSDS interception
capability is a simulated feature based on public claims.

References:
- Wikipedia: Active protection system
  https://en.wikipedia.org/wiki/Active_protection_system

## Audio

`generated/audio/{shot,rocket,launcher}.wav` are original deterministic PCM16 mono 44.1 kHz impulse/noise sounds generated by `APSWave.Synthesize`, covered by this project's MIT license. Runtime uses the same synthesis if shipped WAV files cannot be loaded. No sampled video audio or third-party recordings are redistributed.

No real APS firing reference was listened to or verified in this pass. These sounds are **synthetic**, not genuine hardware recordings or verified reference-inspired matches.

Legacy `assets/Models` and its old generator/icon headers still carry their own GPL-3.0-only labels. Those assets are not included by `release.ps1`; this metadata correction does not relicense previously GPL-labelled files.
