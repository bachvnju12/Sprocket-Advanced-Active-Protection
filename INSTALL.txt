SPROCKET ADVANCED APS (SAAPS) - INSTALL GUIDE
============================================
Version: 1.0.0
Game: Sprocket 0.2.55.5 / Unity 6000.3.21f1 / Windows x64
Loader: BepInEx 6.0.0-be.788 IL2CPP
Dependency: Sprocket Mod API >=1.1.0, <2.0.0

INSTALL
-------
1. Close Sprocket. Back up existing SAAPS files and customized config.
2. Extract release ZIP directly beside Sprocket.exe, not inside another folder.
   ZIP root contains:
   BepInEx/plugins/SprocketAdvancedAPS.dll
   BepInEx/plugins/SprocketAdvancedAPS/sprocket-mod.json
   BepInEx/plugins/SprocketAdvancedAPS/meshes/saaps_*.json (10)
   BepInEx/plugins/SprocketAdvancedAPS/icons/saaps_*.png (10)
   BepInEx/plugins/SprocketAdvancedAPS/textures/saaps_surfaces.png
   Sprocket_Data/StreamingAssets/Parts/saaps_*Part.json (10)
   Sprocket_Data/StreamingAssets/Localization/en-UK/Parts/saaps_*.xml (10)
   ConfigExamples/sprocket.advancedaps.cfg
   README.md, INSTALL.txt, CHANGELOG.md, CREDITS.md, VERIFICATION.md, LICENSE
   SHA256SUMS.txt
3. Existing BepInEx/config/sprocket.advancedaps.cfg is NOT overwritten.
   BepInEx creates defaults on first run. Optional template lives under
   ConfigExamples; copy it to BepInEx/config only when no customized config exists.
4. Launch game. Open Firepower > Active Protection Systems.
   Old APS saved as add-on structures must be replaced with new model parts;
   existing saaps_<system> model components retain their identity.

CONFIG
------
Runtime reads BepInEx/config/sprocket.advancedaps.cfg.
Config/default-aps-profiles.json in source is reference data, NOT a loaded preset.
Speed limits and probability multipliers are gameplay approximations.
Soft-kill cone is compiled: 30 degrees horizontal (plus/minus 15),
20 degrees vertical (plus/minus 10), around module local +Z.
HUD, F7 coverage and inspector rendering are not implemented.

VERIFY
------
Check BepInEx/LogOutput.log for "[SAAPS] APS model-part runtime loaded".
Enable General/DebugMode for detection/engagement/release logs.
Offline build/tests/ZIP hashes do not prove in-game camo or tracer appearance.
See VERIFICATION.md for remaining live checks.

UPGRADE / UNINSTALL
-------------------
Upgrade: back up SAAPS files, then replace ZIP files with game closed.
Keep customized runtime config. Do not remove or replace other mods.
Uninstall: delete only listed SAAPS plugin/assets, ten saaps_* part definitions
and ten saaps_* localization files. Optionally remove SAAPS runtime config.
Blueprints referencing removed parts may need those parts removed in Designer.

BUILD RELEASE FROM SOURCE
-------------------------
powershell -NoProfile -ExecutionPolicy Bypass -File release.ps1
Optional: -GameRoot "D:\Games\Sprocket" -OutputRoot "D:\Releases\SAAPS"
Requires .NET 6 SDK and installed game/BepInEx/ModAPI assemblies.
Runs offline tests, builds Release without deploy, packages ZIP and verifies hashes.
Output: dist/SprocketAdvancedAPS-1.0.0-<timestamp>.zip and .zip.sha256.
Do not commit dist/, bin/, obj/, work/ or local game configs.
Attach ZIP and its checksum to a GitHub Release separately.
