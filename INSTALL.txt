SPROCKET ADVANCED APS (SAAPS) - INSTALL GUIDE
=============================================

Version: 1.0.0
Game: Sprocket 0.2.55.5
Loader: Sprocket Mod Loader (BepInEx 6 IL2CPP)

PREREQUISITES
-------------
1. Sprocket 0.2.55.5 installed.
2. BepInEx 6.0.0-be.788 (IL2CPP) installed in the Sprocket directory.
3. Sprocket Mod API 1.1.x installed (required dependency).

INSTALL STEPS
-------------
1. Close Sprocket.
2. Download the SAAPS release ZIP.
3. Extract the ZIP into the directory that contains Sprocket.exe.
   The ZIP contains:

   SprocketAdvancedAPS/
   ├── BepInEx/
   │   ├── plugins/
   │   │   ├── SprocketAdvancedAPS.dll
   │   │   └── SprocketAdvancedAPS/
   │   │       ├── Config/
   │   │       │   └── default-aps-profiles.json
   │   │       ├── Assets/
   │   │       │   ├── Models/
   │   │       │   ├── Icons/
   │   │       │   └── Audio/
   │   │       └── Parts/
   │   │           ├── drozd1RadarPart.json
   │   │           ├── drozd1LauncherPart.json
   │   │           ├── drozd1SensorPart.json
   │   │           ├── ... (30 part files total)
   │   │           └── zaslinSensorPart.json
   │   └── config/
   │       └── sprocket.advancedaps.cfg  (created on first run)
   ├── README.md
   ├── INSTALL.txt
   ├── CHANGELOG.md
   ├── CREDITS.md
   ├── VERIFICATION.md
   └── LICENSE

4. Launch Sprocket.
5. Open the Vehicle Designer. APS parts appear under the
   "Active Protection Systems" category (tagged aps, apsRadar,
   apsLauncher, apsSensor).

VERIFYING INSTALLATION
----------------------
- Open the game's mod menu; "Sprocket Advanced APS" should be listed.
- Check BepInEx/LogOutput.log for:
  "[SAAPS] Sprocket Advanced APS v1.0.0 loaded successfully!"
- In the Vehicle Designer, search for "Drozd", "Arena", "Afganit",
  "Shtora", "Trophy", "Iron Fist", "AMAP-ADS", or "Zaslin".

TROUBLESHOOTING
---------------
- If the mod does not load, confirm Sprocket Mod API 1.1.x is installed.
- If APS parts do not appear, confirm the Parts/*.json files are in
  BepInEx/plugins/SprocketAdvancedAPS/Parts/.
- If APS does not engage, enable DebugMode in the config and check
  LogOutput.log for [SAAPS] DETECTED / ENGAGE / INTERCEPT lines.
- If another mod registers the same part GUID, a conflict will be
  logged; the conflicting mod should be removed.

UNINSTALLATION
--------------
1. Close Sprocket.
2. Delete BepInEx/plugins/SprocketAdvancedAPS.dll.
3. Delete BepInEx/plugins/SprocketAdvancedAPS/.
4. Optionally delete BepInEx/config/sprocket.advancedaps.cfg.
5. Saved vehicle blueprints referencing removed APS parts will show
   those parts as missing; remove them in the Designer.

UPGRADING
---------
1. Back up BepInEx/config/sprocket.advancedaps.cfg.
2. Replace the DLL and Parts/ directory.
3. Restore your config if you customized it.
